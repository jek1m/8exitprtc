# 8 CHASER

Python Ursina 기반 1인칭 추격형 탈출 게임입니다.

8번 출구의 관찰형 구조에 술래 추격, 제한 시간, 퀴즈 판정을 결합했습니다. 플레이어는 연습층에서 정상 상태를 확인한 뒤, 1층부터 8층까지 이상현상을 판단하고 문제를 풀며 탈출해야 합니다.

## 주요 기능

- 1인칭 복도 탐색
- 연습층과 실제 게임 층 분리
- 술래 NPC 추적
- 층별 제한 시간
- 이상현상 랜덤 적용
- 수학, 파이썬 기초, 이상현상 판정 퀴즈
- 힌트 사용 시 시간 감소 및 술래 속도 증가
- 포탈 출구 연출
- 클리어 결과 로그 표시

## 실행 방법

### 1. 패키지 설치

```bash
python -m pip install -U ursina
```

### 2. 게임 실행

```bash
python 8exit.py
```

## 조작법

| 키 | 기능 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 시점 이동 |
| 1, 2, 3 | 퀴즈 정답 선택 |
| H | 힌트 사용 |
| ESC | 게임 종료 |

## 게임 진행

1. 시작 화면에서 `SPACE`를 눌러 게임을 시작합니다.
2. 연습층에서 정상 복도, 포탈, 표지판, 포스터를 관찰합니다.
3. 포탈에 들어가면 실제 1층 게임이 시작됩니다.
4. 각 층에서 이상현상 여부를 확인하며 출구 구역으로 이동합니다.
5. 퀴즈를 맞히면 다음 층으로 이동합니다.
6. 오답, 시간 초과, 술래에게 잡힘이 발생하면 현재 층을 다시 시작합니다.
7. 8층을 통과하면 탈출 성공 화면과 플레이 기록이 표시됩니다.

## 이상현상 종류

| 이름 | 설명 |
| --- | --- |
| `None` | 변화 없음 |
| `sign_wrong` | 천장 출구 표지판 변경 |
| `gate_red` | 포탈 색상 붉게 변경 |
| `wall_dark` | 좌우 벽 밝기 변경 |
| `poster_changed` | 벽 포스터 이미지 변경 |

이상현상이 있는 층에서는 파이썬 문제 대신 이상현상 여부를 묻는 문제가 출제됩니다.

## 트러블슈팅

### 벽 끼임 문제

플레이어가 벽에 붙으면 벽에 끼거나 이동이 부자연스러운 문제가 있었습니다. 벽 `collider`에만 의존하지 않고, `clamp_to_path()`로 플레이어가 복도 중심 경로 기준 허용 반경 밖으로 벗어나지 않도록 보정해 해결했습니다.

### 술래 추적 버그

플레이어가 벽에 붙으면 술래가 가까이 와도 잡지 못하는 문제가 있었습니다. 술래가 복도 중앙선 기준 위치만 추적하던 것이 원인이었습니다. 같은 복도 구간에서는 실제 플레이어 위치를 직접 목표로 추적하도록 `find_path()`를 수정해 해결했습니다.
